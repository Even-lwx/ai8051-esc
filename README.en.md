# 逐飞科技基于AI8051U的无感无刷驱动开源项目

#### Description
逐飞科技精心设计了基于STC的无感无刷驱动参考方案，该方案使用AI8051U-QFN48，此单片机具有比较器，无需外加比较器。驱动支持低电压保护、堵转保护、上电鸣叫、支持刹车。
