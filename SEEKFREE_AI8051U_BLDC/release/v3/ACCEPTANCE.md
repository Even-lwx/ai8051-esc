## 待实物完成

### MDU32

- [ ] 构建独立测试固件，加入 `tests/mdu32_hardware_selftest.c`，在调用前关闭全局中断并断开电机输出。
- [ ] 从调试器调用 `mdu32_hardware_selftest()`；结束后要求 `mdu32_selftest_failures=0`，输入最终到达 393210。
- [ ] 该测试文件不得加入交付飞行固件；生产固件中 MDU32 仍只能由 Timer0 链访问。

### PWM 输入与失联

- [ ] 信号源测试频率：39、40、50、400、490、491 Hz。
- [ ] 高电平测试：999、1000、1050、1500、2000、2001 us。
- [ ] 40-490 Hz 且 1000-2000 us 为有效闭区间；其他列出边界不得更新 duty 或刷新超时。
- [ ] 单坏帧保持上一 duty；连续坏帧或无信号从最后有效帧起在 75 ms +/- 1 ms 清零输出。
- [ ] 人为制造 CC5OF/CC6OF 后当前帧无效，下一有效帧可恢复且无中断风暴。
- [ ] 有效信号恢复后重新执行原启动流程，不直接跳入闭环。

### ISR 时序

- [ ] 使用测试专用 GPIO 包围 comparator ISR、Timer0 两阶段和 PWMB ISR，测试代码不得进入交付 HEX。
- [ ] comparator ISR <= 5 us。
- [ ] 在正式确认 7 极对后，3000 KV、12.6 V 理论上限为 264600 eRPM；60 度电角扇区约 37.8 us，comparator + 两次 Timer0 总时间必须 < 12.6 us。
- [ ] 若真实极对数不同，先按真实值重新计算门槛。

### 拆桨台架与飞行

- [ ] 9.5、11.1、12.6 V 下重复冷启动、热启动、快速升降油和失联恢复。
- [ ] 不得失步、MCU 复位或异常重启；相同稳态 duty 的空载电流不得明显高于 V2。
- [ ] 相同飞控参数飞行 A/B：命令到角加速度滞后相对 V2 增加 <= 2 ms，目标到 gyro <= 30 ms。
- [ ] 3-4.25 Hz 与 6-7 Hz 峰值均不得比 V2 增加超过 10%。
- [ ] 任一门槛失败，按 `01_pwm_input`、`02_fast_ramp`、`03_mdu32_final` 的顺序烧录定位；安全异常直接回退 V2。
